# PPT 结构规划

## 步骤

1. 确认受众、目的、时长与现有素材。
2. 先写一句核心结论，再安排支持它的证据和行动建议。
3. 每页只承担一个主要观点；写标题、内容要点与适合的图表形式。
4. 数字与引用必须能回到真实来源；缺资料时标记待补，不编造。
5. 输出逐页大纲；需要 PPTX 时使用用户另行配置的演示文稿工具。

## 输入

主题、汇报对象、目标与素材。

## 输出

可交给演示工具制作的逐页大纲，以及待补素材清单。
