# 维护工作台

此 Skill 用于维护 Personal AI Workbench 的任务源与 Skills 库。先确定工作台的实际绝对路径，再阅读该目录的 README.md 和 config.local.json（存在时）。配置与真实任务只能留在本地。

## 更新任务看板

1. 从配置的 task_board_root 定位任务看板；默认是项目内的演示看板。
2. 读取 tasks-data 目录内对应任务的 Markdown。保留稳定 id；修改状态、概要、当前卡点、下一步与事件日志。不要凭空填写完成状态。
3. 使用该看板自己的生成器重建 index.html。内置示例的命令是 `python examples/task-board/build.py`，该命令只修改演示看板；外部看板必须用外部生成器。
4. 在工作台刷新任务。检查任务标题、状态与独立页；卡片上的“复制 HTML 路径”会生成当前快照。复制后将完整文件路径交给能访问同一文件系统的 AI。
5. 新生成的 HTML 可能包含任务内容与本地路径，留在被 Git 忽略的 data 目录；跨电脑交接用下载文件，并在分享前检查内容。

## 更新 Skills 库

1. 已有 Skill 的目录必须在本地 skills_roots 配置内。工作台对这些来源只读；不要直接改第三方来源包。
2. 新能力在 Skills 页面创建草稿，填写用途、步骤、输入、输出和依赖资源。工作台自己的草稿存在本地 data 目录。
3. 检查 frontmatter、引用资源及敏感文件；检查通过不代表执行验证成功。实际使用后单独记录验证结果。
4. 登记、加入常用、选择分类。复制地址提供实际 SKILL.md 的绝对路径；同事无法访问你的磁盘时，使用导出包，并先检查是否含业务资料。
5. 代码开源只提交通用实现与虚构示例。不要提交本地配置、任务、Skills 内容、头像、备份或设备资料。
