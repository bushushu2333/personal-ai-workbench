# 生图需求整理

## 步骤

1. 提取主体、场景、构图、画幅、配色、风格与必需文字。
2. 只追问会影响结果的缺失信息；其余使用清楚的默认假设。
3. 输出一段可复制的提示词，并列出需要用户提供的参考图。
4. 调用用户已经配置并授权的生图工具；本 Skill 不包含 API 或凭据。
5. 对照原始要求检查生成结果；说明尚未满足的部分。

## 输入

一句画面描述，或参考图片与修改要求。

## 输出

结构完整的提示词；已接入生图工具时，附生成结果与实际限制。
