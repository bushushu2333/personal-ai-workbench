# 配图来源与审核

这四张 JPEG 是工作台公开版本在隔离演示环境中的浏览器截图。

- 首页与任务页：任务正文和标题在截图前由实心色块覆盖，保留状态、布局和操作入口。
- Skills 页：仅展示仓库内的 3 个原创示例 Skill，保留名称与复制按钮以说明功能。
- 设备页：仅使用虚构设备和资源指标；示例地址、主机名及域名在截图前覆盖。
- 所有页面都使用通用图标，没有读取作者的真实头像、任务、Skills、设备清单或 AI 会话。

图片不含原始页面源码、EXIF 或 XMP。`scripts/privacy_check.py` 只允许当前已逐张查看的四张图片及对应 SHA-256；替换图片时必须重新检查可见内容及元数据，再更新哈希。哈希检查用于防止未经审核的替换，并不自行判断图片是否已经脱敏。

演示截图不是用户真实工作状态，也不代表远端设备已接入。
